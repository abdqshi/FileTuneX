# دليل صنّاع المحتوى / Creator kit

[تنزيل ويندوز / Windows download](https://github.com/abdqshi/FileTuneX/releases/tag/v0.9.1-beta.1) · [المعرض / Gallery](GALLERY.md) · [التثبيت / Setup](INSTALL_0.9.md)

FileTuneX is a Windows workspace for video, audio, images and ZIP, in Arabic and English. Prepare each file, save tasks, then run the queue. Developed by Abdalrahman Alqashi / عبدالرحمن القشي.

مساحة عمل لتحويل الفيديو والصوت والصور وZIP بالعربية والإنجليزية. اضبط كل ملف، احفظ المهام، وشغّل الطابور وقت ما تكون جاهز.

## Suggested demonstration / تجربة مقترحة

1. Show light/dark themes and switch between Arabic and English.
2. Import generated sample files and adjust one file independently.
3. Save tasks, select several jobs and demonstrate the queue.
4. Show file-information cards, your device's GPU checks and ZIP tools.
5. Explain that the installer includes .NET; media tools can be downloaded and activated from Settings; manual selection is retained.

Use generated samples rather than personal media. Keep passwords and personal file paths out of recordings. Do not present one device's GPU results as universal, or imply unavailable features. The current preview has no Windows publisher certificate.

استخدم عينات مولّدة، وأخفِ كلمات المرور ومساراتك الشخصية من التسجيل. لا تعمم أداء GPU على كل الأجهزة، ولا تعرض ميزات غير متاحة. النسخة الحالية لا تحمل شهادة ناشر Windows.
