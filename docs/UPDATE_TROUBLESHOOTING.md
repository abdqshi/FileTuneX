# Update help / مساعدة التحديثات

افتح الإعدادات ← التحديثات، أو زر التحديثات أسفل التطبيق. نسخة ZIP القديمة تحتاج تثبيت النسخة الجديدة أولًا؛ لا تدعم تحديثًا ذاتيًا داخل مجلد فك الضغط. أغلق النسخة القديمة قبل التثبيت. بيانات النسخة المثبّتة تبقى خارج مجلد البرنامج.

Open Settings → Updates or the shell Updates button. Close legacy ZIP copies before installing the new edition; ZIPs cannot update in place. Installed data stays outside the program directory.

| الحالة / Message | الإجراء / Action |
|---|---|
| Offline / لا اتصال | Restore the connection and retry after the cooldown. أعد الاتصال وحاول لاحقًا. |
| Feed unavailable / لا توجد بيانات موثوقة | A signed feed is missing; do not substitute another website. قد لا يكون التحديث منشورًا بعد. |
| Rate limited / تأجيل الفحص | Wait for the server deadline; restarting does not clear it. انتظر الموعد المحدد. |
| Untrusted, expired or wrong package / تعذر التحقق | Stop and report the friendly error/version. لا تتجاوز الفحص ولا ترسل كلمات المرور. |
| Disk space / المساحة | Free space on the installation drive and retry. وفّر مساحة ثم أعد المحاولة. |
| Active work / توجد مهمة | Download now, install later, or finish the queue. Cancellation needs separate consent. يمكنك تأجيل التثبيت. |
| Restart declined / تأجيل التشغيل | Continue working; a downloaded update will not auto-apply on startup. يمكنك متابعة عملك. |
| Update not applied / لم يكتمل | Preserve data, close installed instances and retry an authenticated official installer. لا تحذف بياناتك. |

Stable excludes Beta. Returning to Stable never silently downgrades a newer installed Beta. Native logs can contain local paths; share reviewed excerpts only, never the password vault, passwords or access codes. Reinstall-based recovery is distinct from automatic rollback, which has not been qualified.
