# التحقق من التنزيل والتحديث / Download and update checks

Download sizes and hashes have been checked, and the update package is validated against its signed release metadata. Beta is an explicit choice and is excluded from Stable.

جرى فحص أحجام التنزيل وبصماته، ويُتحقق من حزمة التحديث وفق بيانات الإصدار الموقعة. Beta خيار صريح ولا تصل تلقائيًا لمستخدمي Stable.

This is a Beta preview. A live GitHub-to-installed upgrade and automatic rollback are not fully qualified. The installer currently has no Authenticode publisher certificate. A valid package signature does not remove Windows publisher warnings. Use the official download page and do not bypass a failed integrity check.

هذه نسخة تجريبية، والترقية المثبّتة من GitHub مباشرة والتراجع التلقائي غير معتمدين باختبار كامل. المثبّت لا يحمل شهادة ناشر Windows حاليًا، وتوقيع الحزمة لا يلغي تحذيرات Windows. لا تتجاوز فشل التحقق من سلامة التنزيل.
