# الصيغ المدعومة / Supported output profiles

| Group / المجموعة | Profiles / الصيغ |
|---|---|
| Video / فيديو | MP4, MKV, WebM, AVI, MOV |
| Audio / صوت | MP3, WAV, FLAC, M4A, Opus, Ogg, AIFF |
| Images / صور | PNG, JPEG, WebP, BMP, TIFF, AVIF |
| Archives / الأرشيف | ZIP, optional AES-256 password protection |

Codec/container compatibility and installed engine capabilities still apply. Media processing selects the first video/audio streams and a still frame for images. Complete HDR, metadata, multitrack, subtitles and animation preservation are not guaranteed. GPU availability varies with the device, driver and codec. See [known limitations](KNOWN_LIMITATIONS.md).

التوافق يعتمد على الحاوية والترميز والمحرك المتوفر. تُعالج أول مسارات الفيديو والصوت وإطار ثابت للصور. لا يوجد ضمان شامل لحفظ HDR أو البيانات الوصفية أو المسارات المتعددة أو الترجمة أو الحركة. دعم GPU يعتمد على الجهاز والتعريفات والترميز.
