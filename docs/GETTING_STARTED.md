# ابدأ مع FileTuneX / Getting started

[دليل التثبيت بالعربية والإنجليزية / Installation guide](INSTALL_0.9.md) · [المعرض / Gallery](GALLERY.md) · [حل مشاكل التحديث / Update help](UPDATE_TROUBLESHOOTING.md)

نزّل النسخة من صفحة الإصدار الرسمية. المثبّت يتضمن .NET، وأدوات ZIP تعمل مباشرة. تحويل الوسائط يحتاج FFmpeg وFFprobe منفصلين.

Download from the official release page. The installer includes .NET and ZIP works directly. Media conversion needs separately supplied FFmpeg and FFprobe.
