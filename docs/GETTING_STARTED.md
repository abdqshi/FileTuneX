# FileTuneX — Start here / ابدأ هنا

Developed by Abdalrahman Alqashi · تطوير عبدالرحمن القشي

## العربية
1. نزّل مثبّت Windows x64 من صفحة الإصدارات وشغّله. .NET مرفق.
2. لتحويل الوسائط، اضغط «جهّز محرك الوسائط» من الرئيسية، ثم «تنزيل وتجهيز المحرك» في الإعدادات.
3. ينتقل التنزيل عبر HTTPS من إصدار Gyan Doshi المحدد على GitHub. نفحص الحزمة والأدوات قبل تفعيلها، ثم نحفظ مساراتها تلقائيًا.
4. يمكنك إلغاء التجهيز أو إعادة المحاولة؛ أدواتك السابقة تبقى محفوظة عند الفشل. الاختيار اليدوي لـffmpeg.exe وffprobe.exe ما زال متاحًا.
5. أضف الملفات، اضبط كل ملف، احفظ مهامه في الطابور، ثم ابدأ.

التنزيل الاختياري: FFmpeg/FFprobe 9.0.2، بحجم 109.5MiB، مع نحو 650MB مساحة فارغة للتجهيز. الأدوات الخارجية بترخيص GPL v3 وتبقى إشعاراتها ومصدرها متاحين. ZIP يعمل مباشرة دون هذا التنزيل. كروت الشاشة تُكتشف دون الأدوات، لكن اختبار الترميز والتحويل يحتاجان محرك وسائط جاهزًا.

## English
1. Download and run the Windows x64 installer. .NET is included.
2. For media conversion, choose Set up media tools on Home, then Download and set up in Settings.
3. The pinned Gyan Doshi package downloads from its version-specific GitHub release over HTTPS. Package and tool checks complete before activation; paths are saved automatically.
4. Cancel or retry as needed. Failed setup keeps your previous tools/settings. Manual ffmpeg.exe and ffprobe.exe selection remains available.
5. Add files, configure each one, save tasks, then start the queue.

Optional media download: FFmpeg/FFprobe 9.0.2, 109.5 MiB; allow about 650 MB free for setup. These external tools use GPL v3, with notices and matching-source links retained. ZIP works without the download. Graphics inventory works independently; encoding tests and media conversion need configured tools.
